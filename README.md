Healthcare Dataset Exploration with R

Project Overview

This project focuses on exploring and analyzing healthcare data using R to identify patterns, understand patient information, and generate meaningful insights.

Objectives

- Explore and understand the healthcare dataset.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify patterns and trends in healthcare data.
- Present findings through an HTML report.

Technologies Used

- R Programming
- Data Analysis
- Exploratory Data Analysis (EDA)
- HTML
